# Калькулятор оценок — домашнее задание №6

Приложение на Python и PyQt6. Продолжение домашней работы №5: к калькулятору оценок добавлены две базы данных — **SQLite** и **PostgreSQL**.

## Возможности

- Выбор СУБД: SQLite или PostgreSQL.
- Добавление оценки от 2 до 5 для выбранного (введённого) предмета.
- Автоматическое создание предмета, если его ещё нет в базе.
- Просмотр двух связанных таблиц «Предметы» и «Оценки».
- Удаление выбранной оценки, обновление данных.
- Расчёт общего среднего балла и количества пятёрок, необходимых для достижения выбранного среднего.
- Сохранение оценок в выбранную БД и их восстановление после перезапуска приложения.

**Важно:** SQLite и PostgreSQL — две самостоятельные базы данных. При переключении данные не переносятся из одной базы в другую. Для демонстрации PostgreSQL нужно отдельно установить и запустить сервер.

## Установка

В терминале в папке `dz6`:

```bash
python -m pip install -r requirements.txt
python grades.py
```

В PyCharm также можно открыть `grades.py` и нажать Ctrl+Shift+F10. Python 3.10+ рекомендуется.

### SQLite

Никаких дополнительных установок не нужно: `sqlite3` встроен в Python. По умолчанию подключается SQLite, рядом с `grades.py` создаётся файл `grades.sqlite3`. Он локальный и включён в `.gitignore`, чтобы не загружать личные учебные данные на GitHub.

### PostgreSQL

1. Установите PostgreSQL Server с официального сайта https://www.postgresql.org/download/windows/ (для Windows установщик обычно включает pgAdmin).
2. При установке запомните пароль пользователя `postgres`. Стандартный порт — `5432`.
3. Откройте **pgAdmin**, подключитесь к локальному серверу и создайте базу данных с именем `grade_calculator` (Databases → Create → Database). **Таблицы вручную создавать не нужно.**
4. Запустите приложение, выберите в списке **PostgreSQL**. В открывшемся диалоге укажите сервер `localhost`, порт `5432`, базу данных `grade_calculator`, пользователя `postgres` и пароль, заданный при установке.
5. Нажмите OK. Программа автоматически создаст нужные таблицы, если их ещё нет.

Пароль не записывается в код, README или CSV. Он нужен только при подключении.

## Как пользоваться

1. Выберите SQLite или PostgreSQL.
2. Введите название предмета, например `Математика`, и выберите оценку `5`.
3. Нажмите «Добавить оценку». Запись сохранится в выбранной базе.
4. Перейдите на вкладку «Оценки», чтобы увидеть запись с названием предмета. На вкладке «Предметы» будет одна строка с предметом. Ещё одна оценка с тем же названием предмета не создаст дубль в таблице `subjects`.
5. Чтобы удалить оценку, выделите строку во вкладке «Оценки» и нажмите «Удалить выбранную оценку».
6. Выберите желаемый средний балл и нажмите «Рассчитать». Среднее считается по **всем оценкам выбранной базы**, независимо от предмета.

## Структура связанных таблиц

Обе СУБД используют одинаковую логическую схему:

| Таблица | Поля |
| --- | --- |
| `subjects` | `id` — первичный ключ, `name` — название предмета, обязательное и уникальное |
| `grades` | `id` — первичный ключ, `subject_id` — внешний ключ к `subjects.id`, `value` — оценка от 2 до 5 |

**Один ко многим:** одному предмету может соответствовать много оценок, но каждая оценка относится к одному предмету.

Ограничения `NOT NULL`, `UNIQUE`, `CHECK` и внешний ключ помогают поддерживать корректность данных. Для SQLite включается проверка внешних ключей через `PRAGMA foreign_keys = ON`.

## Какие SQL-запросы используются

Создание таблицы предметов (вместо `{primary_key}` код подставляет синтаксис выбранной СУБД):

```sql
CREATE TABLE IF NOT EXISTS subjects (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL UNIQUE CHECK (length(trim(name)) > 0)
);
```

Создание таблицы оценок:

```sql
CREATE TABLE IF NOT EXISTS grades (
    id INTEGER PRIMARY KEY,
    subject_id INTEGER NOT NULL REFERENCES subjects(id),
    value INTEGER NOT NULL CHECK (value BETWEEN 2 AND 5)
);
```

В PostgreSQL поле `id` использует `INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` вместо `INTEGER PRIMARY KEY`.

Запись предмета и оценки:

```sql
SELECT id FROM subjects WHERE name = ?;
INSERT INTO subjects (name) VALUES (?);
INSERT INTO grades (subject_id, value) VALUES (?, ?);
```

Знак `?` применяется в SQLite; в PostgreSQL используется `%s`. Значения передаются отдельно через параметры `execute()`, а не вставляются в строку SQL.

Вывод оценок с предметами:

```sql
SELECT grades.id, subjects.name, grades.value
FROM grades
JOIN subjects ON subjects.id = grades.subject_id
ORDER BY grades.id DESC;
```

Удаление оценки:

```sql
DELETE FROM grades WHERE id = ?;
```

При сохранении изменения подтверждаются через `commit()`, а при ошибке отменяются через `rollback()`. Соединение закрывается через `close()`.

## Как проверить

1. Выберите SQLite, добавьте предмет `Математика` и оценку `5`. Во вкладках должны появиться предмет и одна оценка.
2. Добавьте тому же предмету оценку `4`. Во вкладке «Предметы» должна остаться одна строка, а во вкладке «Оценки» — две. Средний балл будет **4.50**.
3. Закройте программу и запустите заново. Оба результата должны сохраниться.
4. Добавьте предмет `Физика` и оценку `3`. Проверьте, что у разных предметов разные ID, а строки оценок связаны с нужным предметом.
5. Выберите PostgreSQL и подключитесь к заранее созданной базе. Записи из SQLite **не должны автоматически появиться**. Добавьте в PostgreSQL новую оценку и проверьте её во вкладках.
6. Вернитесь к SQLite — ранее сохранённые там оценки должны снова отображаться.

## Итог

Программа демонстрирует подключение двух СУБД из одного графического приложения, создание связанных таблиц с первичными и внешними ключами, выполнение SQL-команд `CREATE TABLE`, `SELECT`, `INSERT`, `DELETE`, `JOIN`, а также работу транзакций.
