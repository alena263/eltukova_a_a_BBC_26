# Калькулятор оценок

Домашняя работа №5

**«Калькулятор оценок»** — настольное приложение на Python и PyQt6, которое позволяет студентам рассчитывать средний балл и планировать улучшение успеваемости. Пользователь может добавлять оценки, удалять их и узнавать, сколько пятёрок необходимо получить для достижения желаемого среднего балла.

Например, если у студента есть оценки **5, 4, 3, 5**, его средний балл составляет **4,25**. Чтобы повысить его до **4,5**, приложение предложит получить ещё **2 пятёрки**.

## Возможности

- Добавление оценок от **2 до 5** с помощью выпадающего списка.
- Автоматический расчёт среднего арифметического всех добавленных оценок.
- Отображение общего количества оценок.
- Просмотр всех введённых оценок в отдельном списке.
- Удаление выбранной оценки с автоматическим пересчётом среднего балла.
- Выбор желаемого среднего балла из готовых вариантов: **3.0, 3.5, 4.0, 4.5 и 4.8**.
- Расчёт количества пятёрок, необходимых для достижения выбранного среднего балла.
- Вывод сообщения, если желаемый средний балл уже достигнут.
- Проверка наличия оценок перед расчётом и выбора оценки перед удалением.
- Удобный интерфейс со светлым фоном, кнопками и прокруткой окна.

## Требования для запуска

- Установленный **Python 3** с `pip`.
- Библиотека **PyQt6** для создания графического интерфейса.
- Файл `grades.py` с кодом приложения.

## Как пользоваться приложением

1. В поле **«Выберите оценку»** выберите значение от 2 до 5.
2. Нажмите **«Добавить оценку»**. Выбранная оценка появится в списке, а средний балл автоматически пересчитается.
3. Повторите действие для всех необходимых оценок.

5. Если нужно удалить оценку, выделите её в списке и нажмите **«Удалить выбранную оценку»**.
6. В поле **«Желаемый средний балл»** выберите нужное значение.
7. Нажмите **«Рассчитать»**. Программа покажет, сколько пятёрок необходимо получить для достижения выбранного результата.

Например, при оценках `5, 4, 3, 5` и желаемом среднем балле `4.5` программа выведет:

**«Для среднего балла 4.5 нужно получить ещё 2 пятёрки.»**

Если текущий средний балл уже соответствует выбранному значению или превышает его, приложение сообщит:

**«Желаемый средний балл уже достигнут!»**

## Как рассчитывается средний балл

Приложение складывает все добавленные оценки и делит полученную сумму на их количество.

Формула среднего арифметического:

\[
\text{Средний балл}=\frac{\text{Сумма оценок}}{\text{Количество оценок}}
\]

Например, студент получил четыре оценки: 5, 4, 3 и 5.

\[
\frac{5+4+3+5}{4}=\frac{17}{4}=4{,}25
\]

В коде вычисление выполняется строкой:

```python
average = sum(self.grades) / count
```

Здесь `self.grades` — список оценок, `sum()` — функция для вычисления суммы, а `count` — количество оценок.

Результат отображается с точностью до двух знаков после запятой.

## Как рассчитывается количество необходимых пятёрок

Для достижения желаемого среднего балла приложение определяет, сколько дополнительных оценок 5 нужно получить.

При расчёте предполагается, что все оценки имеют одинаковый вес.

В программе используется цикл `while`:

```python
needed = 0

while (total + needed * 5) / (count + needed) < desired:
    needed += 1
```

Здесь:

- `total` — сумма имеющихся оценок.
- `count` — количество имеющихся оценок.
- `desired` — желаемый средний балл.
- `needed` — количество дополнительных пятёрок.

Цикл постепенно увеличивает количество пятёрок, пока новый средний балл не достигнет желаемого значения.

| Имеющиеся оценки | Текущий средний балл | Желаемый балл | Нужно пятёрок |
|---|---|---|---|
| 4 | 4,00 | 4,5 | 1 |
| 5, 4, 3, 5 | 4,25 | 4,5 | 2 |
| 3, 4 | 3,50 | 4,5 | 4 |
| 2, 3, 4 | 3,00 | 4,5 | 9 |
| 5, 5 | 5,00 | 4,8 | 0 |

Например, для оценок 5, 4, 3, 5 после получения двух дополнительных пятёрок средний балл составит:

\[
\frac{5+4+3+5+5+5}{6}=4{,}5
\]

Таким образом, приложение помогает студенту оценить, насколько реально повысить успеваемость.

## Проверка действий пользователя

В приложении предусмотрены проверки, которые предотвращают неправильное выполнение операций.

**1. Попытка рассчитать результат без оценок**

Если пользователь не добавил ни одной оценки и нажал «Рассчитать», откроется окно с сообщением:

«Сначала добавьте оценки!»

**2. Удаление без выбора оценки**

Если нажать «Удалить выбранную оценку», не выделив элемент списка, появится сообщение:

«Сначала выберите оценку в списке!»

**3. Изменение оценок**

При добавлении или удалении оценки программа автоматически пересчитывает средний балл и количество оценок, а предыдущий результат планирования очищается.

**4. Ограничение вводимых значений**

Оценки выбираются из готового списка, поэтому пользователь не может случайно добавить буквы или числа вне диапазона от 2 до 5.

## Как устроен код

Код приложения находится в файле `grades.py`.

- **`GradeCalculator`** — класс главного окна приложения. Он отвечает за создание интерфейса и управление оценками.
- **`__init__()`** — конструктор класса. Создаёт список оценок, окно приложения, кнопки, выпадающие списки и текстовые элементы.
- **`add_grade()`** — получает выбранную оценку, добавляет её в список и вызывает пересчёт среднего балла.
- **`delete_grade()`** — удаляет выделенную оценку. Если ничего не выбрано, показывает предупреждение.
- **`update_average()`** — подсчитывает количество оценок, рассчитывает средний балл и обновляет информацию в окне.
- **`calculate()`** — рассчитывает, сколько пятёрок нужно получить для достижения желаемого среднего балла.
- **`if __name__ == "__main__"`** — точка входа в программу. Создаёт `QApplication`, открывает окно и запускает цикл обработки событий.

Для хранения оценок используется обычный список Python:

```python
self.grades = []
```

При добавлении оценки применяется метод `append()`, а при удалении — `pop()`.

Все расчёты выполняются непосредственно в программе без подключения дополнительных математических библиотек.

## Особенности приложения

Программа рассчитана на обычную пятибалльную систему оценивания. Пользователь может выбрать оценки от 2 до 5, а все введённые оценки учитываются с одинаковым весом.

Данные хранятся в списке во время работы приложения. После закрытия окна список оценок не сохраняется, поэтому при следующем запуске оценки нужно будет добавить заново.

Приложение не требует подключения к интернету и работает локально на компьютере.
